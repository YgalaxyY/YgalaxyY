# Проекты Дениса Буракова

Python, автоматизация и AI-интеграции. У каждого проекта указаны задача, стек и ссылка на доступные материалы.

## Коммерческий продукт

**[Cardora Studio](https://github.com/YgalaxyY/Cardora-AI-Automation)** — продаваемое Windows-приложение для пакетной подготовки фото и карточек товаров. Python, PySide6, локальные Real-ESRGAN и Real-CUGAN через NCNN/Vulkan, адаптивный тайлинг, PSD-смарт-объекты, XLSX-шаблоны и Wildberries API в бета-режиме. [Релиз с установщиком](https://github.com/YgalaxyY/Cardora-AI-Automation/releases/tag/v2.0.0).

## Python, AI и обработка данных

| Проект | Что сделано |
| --- | --- |
| [BookMarkCore](https://github.com/YgalaxyY/GalaxyOS_BookMarkCore) | Telegram-бот распределяет ссылки по категориям через LLM API и публикует HTML через GitHub API. Реализованы разбор JSON, резервная классификация и проверка возможных дублей. |
| [SillyTavern / Local LLM Lab](https://github.com/YgalaxyY/local-llm-roleplay-lab) | Локальный ролевой чат с Llama и Qwen через LM Studio. Настроены персонаж и сценарии, доработан CleanUI. В личной сборке подключена генерация изображений через ComfyUI. |
| [Excel Merge Core](https://github.com/YgalaxyY/concatenate_multiple_excel) | Python-утилита объединяет XLSX-выгрузки в один отчёт. pandas, openpyxl и простой графический интерфейс. |
| [DeepSynth](https://github.com/YgalaxyY/deepsynth-research) | Учебный проект на PyTorch для детекции дипфейков по видео и звуку. Доступны код и протокол оценки. Результаты повторного прогона ожидаются. |
| [Swarm of Agents](https://github.com/YgalaxyY/Swarm-of-agents) | Python-генератор промптов и файлов конфигурации ролей для Roo Code и Ollama. |
