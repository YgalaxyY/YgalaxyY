## Selected projects

**[BookMarkCore](https://github.com/YgalaxyY/GalaxyOS_BookMarkCore)** · Python, aiogram, LLM APIs  
A Telegram bot that categorizes incoming links, checks for possible duplicates and publishes HTML cards through the GitHub API. It handles model response parsing and falls back to other models or rules. [View source](https://github.com/YgalaxyY/GalaxyOS_BookMarkCore/blob/main/main.py).

**[DeepSynth](https://github.com/YgalaxyY/deepsynth-research)** · PyTorch, EfficientNet, FFmpeg  
A student project on combining audio and image scores for deepfake detection as video quality changes. The evaluation protocol includes a source-group holdout and checks for matching clip variants. Benchmarks under the revised protocol are pending. [Read the methodology](https://github.com/YgalaxyY/deepsynth-research/blob/main/docs/METHODOLOGY.md).

**[Cardora](https://github.com/YgalaxyY/Cardora-AI-Automation)** · Python, PySide6, Real-ESRGAN  
A desktop demo for batch preparation of product images using a pretrained upscaler, Photoshop templates and Excel. The public repository shows the workflow and screens. [View screenshots](https://github.com/YgalaxyY/Cardora-AI-Automation#demo).

**[Excel Merge Core](https://github.com/YgalaxyY/concatenate_multiple_excel)** · Python, pandas, openpyxl  
A GUI prototype that combines rows from several XLSX files into one report. The README walks through a small synthetic example and explains the current file and worksheet requirements. [View source](https://github.com/YgalaxyY/concatenate_multiple_excel/blob/master/COOPERATE.py).
